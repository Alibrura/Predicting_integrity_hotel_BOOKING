## 📌 Описание проекта  

Банки хранят огромные объёмы информации о своих клиентах. Эти данные можно использовать для того, чтобы оставаться на связи с клиентами и индивидуально ориентировать их на подходящие именно им продукты или банковские предложения. Обычно с выбранными клиентами связываются напрямую через разные каналы связи (прямой маркетинг). Однако проведение маркетинговых кампаний и взаимодействие с клиентами — это трудозатратно и дорого.

**Бизнес-задача:** Определить характеристики, по которым можно выявить клиентов, более склонных к открытию депозита в банке, и за счёт этого повысить результативность маркетинговой кампании.

**Техническая задача:** Построить модель машинного обучения, которая на основе предложенных характеристик клиента будет предсказывать, воспользуется он предложением об открытии депозита или нет.

---

## 🎯 Основные цели исследования  

- Исследовать данные, а не просто вычислить метрики и создать визуализации.  
- Выявить характерные черты для потенциальных клиентов, чтобы чётко очертить целевую аудиторию.  
- Использовать разные инструменты для повышения качества прогноза.

## 🧱 Структура проекта  

Проект разделён на **5 логических частей**, оформленных в одном Jupyter Notebook в соответствии с шаблоном:

### 1. Первичная обработка данных  
- Обработка пропусков  
- Поиск и обработка выбросов  
- Приведение данных к корректным типам  

### 2. Разведывательный анализ данных (EDA)  
- Анализ распределений признаков  
- Выявление закономерностей  
- Формулировка гипотез  
- Визуализация взаимосвязей с целевой переменной  

### 3. Отбор и преобразование признаков  
- Кодирование категориальных переменных  
- Масштабирование числовых признаков  
- Отбор наиболее информативных признаков  

### 4. Решение задачи классификации: логистическая регрессия и решающие деревья  
- **Логистическая регрессия**  
- **Решающие деревья** с подбором гиперпараметров (глубина)  

### 5. Решение задачи классификации: ансамбли моделей и построение прогноза  
- Случайный лес (Random Forest)  
- Градиентный бустинг (Gradient Boosting)  
- Стекинг моделей (дерево решений + логистическая регрессия + градиентный бустинг)  
- Оптимизация гиперпараметров с помощью **Optuna**
